Lightweight Memory Policy Router

一句话：这是一个面向 Coding / Business Agents 的轻量记忆策略路由器，研究在固定候选记忆和当前任务单元已给定时，如何决定哪些记忆读入上下文、哪些当前信息写入长期记忆、哪些应该跳过。

Agent Memory LoRA 后训练 离线评测 Benchmark Packaging

适合投递方向

AI / LLM / Agent / 后训练 / 评测工程 / 数据构造相关实习。重点展示小模型策略层、严谨评测、负面结果分析和可复现包装。

核心问题

长期智能体如果“什么都记、什么都读”，会带来上下文浪费和记忆污染。这个项目把问题收窄为一个可训练、可评测的 policy layer。

方法概览

输入固定 candidate memories 与 current units；输出 READ / STORE / SKIP，以及 STORE 的目标类别：task_state、service_memory、repo_memory、project_memory、user_profile。

最关键结果

项目 结果
最佳 v0.5g 系统 BF16 LoRA r16 + 1000 targeted-balanced data，RTX 4090 fallback settings。
locked gold_v2_009 Exact 36.0%，Parse 99.3%，READ F1 84.6%，STORE F1 99.0%，SKIP F1 98.1%，Target Acc 100.0%。
污染控制信号 False store rate 1.2%；semantic sensitive-store metric 下 locked gold 为 0/4。
6.4 micro-pilot 2 cases × 7 strategies = 14 个 DeepSeek V4 Flash 响应；内部 rubric 复核显示有记忆上下文的策略优于 no_memory，但没有得到 router 特定优势结论。

最重要限制

这个项目不是检索器、不是记忆数据库、不是 writer / updater / merger，也不是端到端智能体。当前结果来自受控 synthetic benchmark 与 saved-prediction replay；READ 仍是主要瓶颈，6.4 proxy 没有把 router_selected 和 naive/random baseline 清晰地区分开。
