中文简历 Bullet

以下表述适合 AI / LLM / Agent / 后训练 / 评测相关实习。所有指标均来自 locked gold_v2_009 或 v10 benchmark closeout，避免超出证据范围。

1. 极简一行版

构建轻量 Memory Policy Router，基于 Qwen3.5-4B + BF16 LoRA 预测 READ / STORE / SKIP 记忆策略，在 locked gold_v2_009 上达到 36.0% exact、99.0% STORE F1、98.1% SKIP F1、100.0% target accuracy。

2. 技术强化版

设计并评测面向 Coding / Business Agent 的记忆策略路由任务，将固定 candidate memories 与 current units 映射为 READ / STORE / SKIP + STORE target；最佳 BF16 LoRA r16 1000-targeted 配置在 locked gold 上 parse 99.3%、READ F1 84.6%、false store rate 1.2%。

3. Agent / Memory / Eval 方向版

围绕 Agent Memory 污染与上下文浪费问题，搭建固定候选记忆的离线路由 benchmark、no-inference replay demo 与 downstream-lite proxy；结果显示 router_selected 可减少注入记忆数量并保留多数 gold READ recall，但尚未与 naive/random baseline 清晰拉开差距。

4. 后训练 / LoRA 方向版

比较 QLoRA 与 BF16 LoRA r16 小模型记忆路由方案，验证 BF16 本身不是主要收益来源；1000 targeted-balanced 数据显著改善写侧路由，在 locked gold 上 STORE F1 99.0%、SKIP F1 98.1%、target accuracy 100.0%。

5. 工程系统版

完成从数据锁定、训练配置、预测保存、指标复算到 v1.0 文档包装的可复现工程链路；支持无模型推理的 demo、proxy benchmark 和 14-response LLM micro-pilot artifact review。

不建议使用的写法

不建议写法 原因
宣称已经验证了完整下游价值 只有 14-response micro-pilot，且是诊断性质。
宣称是线上可部署的记忆系统 没有真实流量、隐私治理、检索链路或 memory lifecycle。
宣称实现 MemoryOS 本项目只研究策略路由层。
宣称显著降低线上成本 当前只有 context-size proxy，没有线上成本测量。
宣称对所有 baseline 都有优势 6.4 proxy 与 micro-pilot 均没有给出这种结论。
宣称检索器效果提升 candidate memories 是固定输入，未评测 live retrieval。
