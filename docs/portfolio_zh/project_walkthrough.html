Repo Walkthrough

这页面向面试官或 reviewer：从哪里开始看、哪些命令不需要 GPU、哪些文件是 source-of-truth，以及 v1.0 的边界是什么。

建议先看哪些文件

路径 作用
README.md 项目总览、核心结果、限制和复现入口。
docs/PROJECT_OVERVIEW.md 问题动机、任务边界和版本演进。
docs/ARCHITECTURE.md 候选记忆、current units、router、context builder / writer stub 的边界。
docs/TASK_FORMULATION.md READ / STORE / SKIP 任务定义和指标解释。
docs/RESULTS.md v0.5e/v0.5g 结果表和 v10 downstream-lite closeout。
reports/v10/v10_benchmark_synthesis.md 6.4 benchmark synthesis，适合作为 v1.0 closeout 入口。

如何运行 no-inference demo

这些命令只 replay 小 fixture，不加载模型、不需要 GPU。

python3 demo/run_demo.py --list
python3 demo/run_demo.py --case demo/cases/case_001.json
python3 demo/run_demo.py --case demo/cases/case_002.json

如何运行 proxy benchmark

proxy 使用 locked gold 和 saved predictions，估算不同策略注入多少候选记忆。它不是下游回答质量评测。

python3 scripts/run_downstream_lite_proxy.py \
  --gold data/v05e/gold_v2/v05e_gold_v2_009_active_cases.jsonl \
  --predictions data/v05g/model_predictions/bf16_r16_1000_4090_gold_v2_009_predictions.jsonl \
  --out-json reports/v10/downstream_lite_proxy_metrics.json \
  --out-md reports/v10/downstream_lite_proxy_report.md

文件 用途

哪些内容不需要 GPU

  • 阅读 README / docs / reports。
  • 运行 demo fixture replay。
  • 运行 saved-prediction proxy benchmark。
  • 解析 JSONL、复核 metrics、查看 prompt pack 和 response artifacts。

Source-of-truth

  • Project scope: docs/planning/lightweight_memory_policy_router_project_spec.md
  • Locked gold: data/v05e/gold_v2/v05e_gold_v2_009_active_cases.jsonl
  • Gold SHA-256: f5cf7be1d06f085e62b87cf0b9c8021119b54ed94968bb5519b3150995eb4f72
  • Saved predictions: data/v05g/model_predictions/
  • v0.5g metrics: reports/v05g/server_runs/

哪些文件不要提交

  • .env 或任何 secret。
  • adapter 权重、*.safetensors、base model。
  • 日志、wandb runs、大型临时输出。
  • 本地缓存、虚拟环境、系统文件。

v1.0 边界

v1.0 是 saved-prediction / artifact-replay / benchmark packaging，不是 live inference system。它的价值在于结果可复核、边界清晰、失败点可解释，并为后续 live LoRA 和 memory-agent demo 留出路线。

相关来源：demo README、Downstream-lite proxy、LLM downstream-lite。
