## 11. Why This Is Not Final Train/Dev/Gold

This is a **repaired batch300 training pool candidate**, not final train/dev/gold data. Specifically:

- No train/dev/gold split has been created
- No gold set has been locked
- The data has not been reviewed for dev/gold representativeness
- Hyperparameter tuning has not been performed
- The batch500 scale-up has not been completed
- Distribution targets are close but not exact (svc at 37.3% vs 30-34%)
- Tag coverage gaps exist (related_but_useless, service_vs_task_state, sensitive_boundary, repo_vs_service)

This data should only be used as seed for batch500 generation, not directly for training.

## 12. Recommendation

**Proceed to batch500 generation.** The repaired batch300 has resolved all critical quality blockers. The remaining distribution deviations (svc overshoot, tag coverage gaps) can be addressed during batch500 generation by:
- Adding proportionally more task_state, repo_memory, and project_memory units
- Adding more tag-specific cases (related_but_useless, boundary tags)
- Limiting new service_memory additions
